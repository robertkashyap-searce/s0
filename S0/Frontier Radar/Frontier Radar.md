# Frontier Radar

Part of the 40% frontier slice ([[S0 Charter]] §4.1). Within **48 hours** of any major model/platform release: ship a Day-Zero Release Note.

## Day-Zero Release Note — required contents
- What changed (the release, in one paragraph)
- What it shifts in our reference architectures ([[Architecture Hub]])
- What it makes newly possible for clients
- Eval-backed verdict on real client-shaped workloads (methodology from [[Benchmark Discipline]])

Opinions expire; evals don't — no note ships without a benchmark run behind it.
