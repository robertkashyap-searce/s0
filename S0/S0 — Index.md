## Frontier workstreams (the 40%, in charter order)
1. [[Frontier Radar]] — Day-Zero Release Notes, ≤48h of any major model release.
2. [[Benchmark Discipline]] — **internal-only.** Never publish raw results externally.
3. [[Architecture Hub]] — reference architectures, paved roads, road-deviation notes.
4. [[Field Response Desk]] — same-day eval-grounded answers to "what's our position on X"; also the ICU intake point.

## Rhythm cadence (from the charter)
- Weekly: squad sync (60 min)
- ≤48h per major model release: Day-Zero Release Note
- Monthly: ≥1 reference architecture, ≥1 white paper/build, 1 teach-in
- Quarterly: benchmark sweep, State of the Frontier readout, pattern handoff, time-contract reconciliation, qualification review
