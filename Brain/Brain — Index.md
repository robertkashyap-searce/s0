## How to read a node

Nodes are append-only. Each `## Ingest — <date>` block is one dump, never rewritten. Contradictions between ingests are flagged, never resolved.

## Using this

Drop `.txt` or `.md` files into `Brain/_Dump/`, then run `/distill`. Nothing here is written by hand.

`Brain/Nodes/` and `Brain/_Sources/` are tracked in the public repo and pushed by Obsidian Git on its timer. `Brain/_Dump/` is gitignored and never leaves this machine.
